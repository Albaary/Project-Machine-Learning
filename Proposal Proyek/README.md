Proposal kami yang berjudul "Klasifikasi Glaukoma pada Citra Retina Menggunakan MobileNetV2 sebagai feature extraction dan Multilayer Perceptron (MLP)" mengajukan pengembangan sistem klasifikasi glaukoma pada citra retina menggunakan MobileNetV2 sebagai feature extraction dan MLP sebagai classifier untuk membedakan citra retina glaukoma dan non-glaukoma.
