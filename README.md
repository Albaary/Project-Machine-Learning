Hillel-Yaffe Dataset for Glaucoma Detection berisi 747 citra fundus retina untuk deteksi glaucomatous optic neuropathy (GON). Dataset terdiri dari gambar retina dengan label GON+ (indikasi glaukoma) dan GON− (non-glaukoma), serta dilengkapi anotasi label glaukoma dan skor kualitas citra. Dataset memiliki ukuran sekitar 130 MB dengan format gambar .jpg.
