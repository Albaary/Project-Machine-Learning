# UAS Pembelajaran Mesin
## Proyek
**Judul**: Klasifikasi Glaukoma pada Citra Retina Menggunakan MobileNetV3 sebagai feature extraction dan Multilayer Perceptron (MLP)<br>
**Topik**: Klasifikasi citra retina untuk mendeteksi glaukoma berdasarkan fundus image

## Progres
Pada tahap ini, telah dilakukan proses preprocessing dataset citra retina serta pelatihan model deep learning untuk klasifikasi glaukoma dan non-glaukoma. Model dilatih menggunakan data train dan divalidasi menggunakan data validation selama 30 epoch dengan evaluasi menggunakan metrik AUC dan F1-Score. Berdasarkan hasil pelatihan, performa terbaik model diperoleh pada epoch ke-25 dengan Validation AUC sebesar 0.8285 dan F1-Score sebesar 0.7267.
